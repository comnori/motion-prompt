// 팩: photo (사진 표현·조명·스타일) · element 02 · 분류: 조명과 시간대
// 동작 요약: 주변이 어두워지고 뒤쪽 좌우 조명이 머리와 어깨 양옆에만 가는 빛 테두리를 만듭니다. 오른쪽 아래 평면도에 두 조명 위치를 표시합니다.
// 동작 사양:
//   - 장면 1: y 150 수평선 앞의 상반신 인물(머리 중심 x 270, y 78, 반지름 29 px, 얼굴·머리카락 없음).
//   - 배경: 밝은 장면 → 어두운 장면(하늘 #2B2D33, 지면 #24252A). 인물 #4D5A75 → #1F2128.
//   - 밝은 가장자리: 호박색 #FFC75A 인물 복사본 두 개를 좌우 3.5 px와 위 2.5 px로 옮겨 어두운 인물 뒤에 놓습니다(테두리 너비 3.5 px).
//   - 오른쪽 아래 평면도(66×66 px): 위에서 본 조명은 뒤쪽 좌우 ±135°입니다. 오른쪽 위에 “±135°”를 표시합니다.
//   - 시간: 0.4 s부터 1.4 s까지 효과가 나타나고 4.0 s까지 유지한 뒤 4.8 s까지 사라집니다(한 번 = 5 s, cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
// 활용 상황: 어두운 배경에서 사람이나 제품을 분리하고 형태를 보여 줄 때 사용합니다.
// 태그: rim light, rim lighting, edge light, backlight, kicker, outline, studio
// 크기: 539x208 px · 반복 주기: 5 s
// 필요한 코드: kit photo -> https://comnori.github.io/motion-prompt/api/v1/kit/photo.js
// 움직이는 예제: https://comnori.github.io/motion-prompt/?lang=ko#098
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 02
// リムライト: 周りが暗くなり、斜め後ろ左右の2灯で頭と肩の輪郭だけが細く光る
CELLS[1] = cell((k, u) => {
  const a = env(u);
  stagePortrait(k, pal(BASE, DARK, a));
  k.save(); k.globalAlpha = a; k.fillStyle = BASE.lit;
  for (const dx of [-3.5, 3.5]) { k.save(); k.translate(dx, -2.5); bustPath(k, PX, PY, PR); k.fill(); k.restore(); }
  k.restore();
  bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
  plan(k, [[Math.PI * 0.75, a], [-Math.PI * 0.75, a]]);
  hud(k, '±135°');
});
