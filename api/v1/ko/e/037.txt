// 동작 요약: 고정 카메라 앞에서 사람이 천천히 점프하고 나뭇잎이 느리게 떨어집니다. 동작 전체를 길게 늘여 보여 줍니다.
// 동작 사양:
//   - 카메라: 완전히 고정(높이 1.3 m). 피사체만 움직입니다.
//   - 피사체: 7 m 거리의 사람이 3.8 s 동안 한 번 점프합니다(0.5 s부터 4.3 s). 높이 = 4q(1-q)×1.1 m이며 최고점 1.1 m의 포물선입니다. q는 시간에 따라 선형 증가합니다.
//   - 공중에서는 양팔을 올립니다. 점프 전 0.5 s와 착지 후 0.4 s 동안 서 있습니다.
//   - 나뭇잎: 9개가 4.7 s 동안 3.4 m 높이에서 바닥까지 회전하며 떨어집니다. 각각 주기의 1/9만큼 시차를 둡니다.
//   - 오른쪽 위에 "120fps ×0.25"를 표시합니다(재생 시간을 4×로 늘림).
//   - 별도의 정지나 크로스페이드 없이 4.7 s마다 매끄럽게 반복합니다.
// 활용 상황: 짧은 동작이나 표정을 자세히 보게 하거나 감정의 절정을 강조할 때 사용합니다.
// 태그: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#037
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
