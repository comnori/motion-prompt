// 동작 요약: 한 사람의 뒤통수와 어깨가 화면 가장자리를 차지하고 그 너머 상대를 봅니다. 전경은 흐리고 상대는 선명합니다.
// 동작 사양:
//   - 구도: 앞사람의 회색 뒤통수·어깨(왼쪽 0.62 m, 거리 1.15 m)가 왼쪽 경계를 채웁니다. 파란 상대(오른쪽 0.32 m, 거리 3.1 m)는 어깨 너머로 보입니다.
//   - 초점: 전경 어깨에 2.6 px 블러, 상대는 선명하며 가슴 위로 잡습니다.
//   - 카메라: 높이 1.55 m, 요 +0.05 rad. 0.5–3.4 s에 0 m → 0.35 m 천천히 전진합니다(cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
//   - 상대는 말하듯 팔·다리를 0.35·sin(u×5) rad로 흔듭니다.
//   - 복귀: 3.4–4.2 s에 정지하고 마지막 0.5 s 동안 시작 화면으로 크로스페이드합니다. 오른쪽 위에 OTS를 표시합니다.
// 활용 상황: 대화에서 누가 누구를 마주 보는지 보여 주고 상대의 표정에 집중할 때 사용합니다.
// 태그: over-the-shoulder, ots, dialogue, conversation, shoulder, two shot, angle
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#180
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 12
// 12 オーバーザショルダー: 手前の人物の肩と後頭部を画面の端に入れ、肩越しに相手を撮る。手前はぼけ、相手にピント
CELLS[11] = shot(camCell((k, w, h, p, u) => {
  world(k, w, h, cam({ z: lerp(0, 0.35, p), y: 1.55, yaw: 0.05 }), {
    person: { x: 0.32, z: 3.1, walk: 0.35 * Math.sin(u * 5) }, blurFg: 2.6,
    extra: [[-0.62, 0, 1.15, (kk) => { kk.fillStyle = C.g4; kk.beginPath(); kk.arc(0, 1.63, 0.17, 0, 7); kk.fill(); rr(kk, -0.34, 0.9, 0.68, 0.6, 0.14); kk.fill(); }, true]]
  });
}, p => 'OTS'));
