// 프리즈 프레임 / Freeze frame
// 팩: camera (카메라 움직임과 장면 전환) · element 16 · 분류: 촬영 방식과 시간 연출
// 동작 요약: 점프하는 사람이 최고점에 도착하면 화면이 멈췄다가 1.4 s 후 같은 프레임에서 다시 움직입니다.
// 동작 사양:
//   - 카메라: 완전히 고정(높이 1.3 m). 멈추는 것은 영상 시간입니다.
//   - 정지: 1.6 s에 멈추고 3.0 s에 재개합니다(1.4 s). 영상 시간은 0–1.6 s 동안 정상 진행하다가 정지 중 1.6 s를 유지하고, 이후 u-1.4로 이어집니다.
//   - 피사체: 7 m 거리의 사람이 영상 시간 0.6–2.6 s 동안 최고점 1.1 m의 포물선으로 점프합니다. 정확히 최고점(50% 지점)에서 멈춥니다.
//   - 떨어지는 나뭇잎 아홉 개도 함께 멈춥니다. 13 Slow motion보다 1.5× 빠르게 떨어집니다.
//   - 정지 표시: 5 px 파란 테두리와 아래 중앙의 일시 정지 아이콘(68×40 px 흰 둥근 상자에 파란 막대 두 개)이 0.12 s 동안 나타나고 사라집니다.
//   - 오른쪽 위에 정지 중에만 "FREEZE"를 표시합니다. 초기화 크로스페이드는 없습니다.
// 활용 상황: 결정적 순간을 강조하거나 화면 위에 이름·자막을 얹을 시간을 줄 때 사용합니다.
// 태그: freeze frame, still frame, pause, hold, stop motion, highlight
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#040
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 16
// 16 フリーズフレーム
CELLS[15] = shot((k, w, h, u) => {
  // 跳躍の頂点で 1.4 秒止める
  const tj = u < 1.6 ? u : u < 3.0 ? 1.6 : u - 1.4;   // 実時間→映像時間
  const q = P(tj, 0.6, 2.6);
  const frozen = u >= 1.6 && u < 3.0;
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(tj, 1.5) });
  if (frozen) {
    const a = Math.min(1, (u - 1.6) / 0.12, (3.0 - u) / 0.12);
    k.save(); k.globalAlpha = a; k.strokeStyle = C.blue; k.lineWidth = 5; k.strokeRect(2.5, 2.5, w - 5, h - 5);
    k.fillStyle = 'rgba(255,255,255,.88)'; rr(k, w / 2 - 34, h - 58, 68, 40, 8); k.fill();
    k.fillStyle = C.blue; k.fillRect(w / 2 - 12, h - 49, 8, 22); k.fillRect(w / 2 + 4, h - 49, 8, 22); k.restore();
  }
  return frozen ? 'FREEZE' : '';
});
