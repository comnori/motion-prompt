// 팩: camera2 (카메라 움직임과 장면 전환 2) · element 04 · 분류: 카메라 움직임
// 동작 요약: 걷는 사람을 컷 없이 한 쇼트로 따라가며 아래 막대도 끊기지 않은 하나의 띠로 남습니다.
// 동작 사양:
//   - 연결: 없음. 4.2 s 동안 한 쇼트로 사람을 따라갑니다(#041 Jump cut은 다섯 개로 나눔).
//   - 피사체: 사람이 왼쪽 앞(x = -3.4 m, 깊이 5.2 m)에서 오른쪽 뒤(x = 2.8 m, 깊이 9.6 m)로 등속 이동합니다. 팔·다리는 sin(t×7)×0.42 rad로 흔들립니다.
//   - 카메라: 사람을 따라 오른쪽 0 m → 1.4 m 이동하면서 회전합니다. yaw = atan2(person x - camera x, depth)×0.8, 높이 1.4 m.
//   - 아래 띠: 재생 헤드가 있는 파란 막대 하나에 “1ショット・カットなし”(한 쇼트·컷 없음)를 표시해 단절이 없음을 보여 줍니다.
//   - 복귀: 4.2 s에 멈추고 마지막 0.5 s 동안 시작 화면으로 크로스페이드합니다(한 번 = 4.7 s).
//   - 오른쪽 위 경과 시간: NO CUT 0.0s → 4.2s.
// 활용 상황: 긴장과 현장감을 끊지 않거나 연속 동작을 하나의 흐름으로 보여 줄 때 사용합니다.
// 태그: long take, oner, one shot, continuous, no cut, sequence shot, camera move
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#172
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 04
// 04 長回し: 歩く人物をカットなしで追い続ける1ショット。画面下の帯は1本のまま（#041 ジャンプカットのように割れない）
CELLS[3] = shot((k, w, h, u) => {
  const uu = Math.min(u, CYC - RESET);
  const draw = (kk, t) => {
    const p = t / (CYC - RESET);
    const x = lerp(-3.4, 2.8, p), z = lerp(5.2, 9.6, p), cx = lerp(0, 1.4, p);
    world(kk, w, h, cam({ x: cx, y: 1.4, yaw: Math.atan2(x - cx, z) * 0.8 }), { person: { x, z, walk: t * 7 }, fg: [[-2.6, 3.4], [3.6, 4.6, 'rock']] });
    strip(kk, w, h, [[0, CYC, '1ショット・カットなし', C.blue]], t);
  };
  const r = P(u, CYC - RESET, CYC);
  blend(k, kk => draw(kk, uu), kk => draw(kk, 0), eIOs(r));
  return `NO CUT ${(r > .5 ? 0 : uu).toFixed(1)}s`;
});
