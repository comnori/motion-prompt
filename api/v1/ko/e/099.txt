// 실루엣 / Silhouette
// 팩: photo (사진 표현·조명·스타일) · element 03 · 분류: 조명과 시간대
// 동작 요약: 밝은 저녁 하늘에 노출을 맞추면 사람·건물·가로등·나무의 세부가 사라져 검은 실루엣이 되고 하늘만 밝게 남습니다.
// 동작 사양:
//   - 장면 1: y 150 수평선 앞의 상반신 인물(머리 중심 x 270, y 78, 반지름 29 px, 얼굴·머리카락 없음).
//   - 하늘: 위는 #FAF9F7 → #FFEDC4, 수평선 부근(y 92–150)은 #FFCF73 띠.
//   - 하늘 외에는 모두 #2A2D36, 먼 언덕은 #4A4546, 인물은 #22252D가 됩니다.
//   - 해: x 404, 반지름 20 px. y 60에서 y 128로 내려가며 언덕에 절반 가려집니다.
//   - 오른쪽 위 표시: ±0.0 EV → −2.0 EV.
//   - 시간: 0.4 s부터 1.4 s까지 효과가 나타나고 4.0 s까지 유지한 뒤 4.8 s까지 사라집니다(한 번 = 5 s, cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
// 활용 상황: 일몰이나 밝은 창을 배경으로 형태와 자세만으로 이미지를 표현할 때 사용합니다.
// 태그: silhouette, backlit, sunset, contre-jour, black shape, underexposed
// 크기: 539x208 px · 반복 주기: 5 s
// 필요한 코드: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#099
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 03
// シルエット: 露出を明るい空に合わせると、人物も建物も木も黒い形だけになる
CELLS[2] = cell((k, u) => {
  const a = env(u), INK = '#2A2D36';
  const SILH = mapPal(BASE, () => INK);
  Object.assign(SILH, { sky: '#FFEDC4', sky2: '#FFCF73', far: '#4A4546', sun: BASE.sun, glow: BASE.glow });
  stagePortrait(k, pal(BASE, SILH, a), { sun: [404, lerp(60, 128, a), 20, a] });
  bust(k, PX, PY, PR, mixc(BASE.person, '#22252D', a));
  hud(k, `${(-2 * a).toFixed(1).replace('-0.0', '±0.0')} EV`);
});
