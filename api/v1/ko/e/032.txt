// 동작 요약: 카메라가 뒤로 물러나면서 같은 비율로 줌 인합니다. 사람의 크기는 그대로이고 배경만 다가옵니다.
// 동작 사양:
//   - 카메라: 8 m 앞의 사람까지 거리 d가 3.2 m → 8 m로 늘어납니다(4.8 m 후진). 높이는 1.3 m입니다.
//   - 초점거리: f = 330 × d/8 px, 즉 132 px → 330 px(10mm → 24mm로 표시). 거리 ÷ 초점거리를 일정하게 유지합니다.
//   - 시간: 0.5 s부터 3.4 s까지(2.9 s), cubic ease-in-out(약 cubic-bezier(0.65,0,0.35,1)).
//   - 피사체: 사람은 정지해 있고 화면 속 높이도 일정합니다. 머리(1.8 m)와 발에 너비 160 px의 파란 점선을 표시해 같은 크기임을 보여 줍니다.
//   - 배경: 건물(거리 48 m)은 약 2.2×, 산은 약 2.4× 커져 사람 뒤로 다가옵니다. 사람 앞의 지면은 줄어듭니다.
//   - 복귀: 3.4–4.2 s에 정지한 뒤 마지막 0.5 s 동안 시작 화면으로 크로스페이드합니다(한 번 = 4.7 s).
// 활용 상황: 깨달음의 순간이나 불안·충격을 시각적으로 표현할 때 사용합니다.
// 태그: dolly zoom, vertigo, zolly, push pull, background stretch, unease, camera move
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#032
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 08
// 08 ドリーズーム: 人物の大きさは一定、背景だけ伸び縮み
CELLS[7] = shot(camCell((k, w, h, p) => {
  const d = lerp(3.2, 8, p), f = F0 * d / 8 * 1.0;
  const c = cam({ z: 8 - d, f, y: 1.3 });
  world(k, w, h, c, {
    person: { z: 8 }, trees: true,
    after: (kk, cc) => { const top = proj(cc, 0, 1.8, 8).y, bot = proj(cc, 0, 0, 8).y; kk.strokeStyle = C.blue; kk.lineWidth = 1.6; kk.setLineDash([6, 5]); kk.beginPath(); kk.moveTo(-80, top); kk.lineTo(80, top); kk.moveTo(-80, bot); kk.lineTo(80, bot); kk.stroke(); kk.setLineDash([]); }
  });
}, p => mm(F0 * lerp(3.2, 8, p) / 8)));
