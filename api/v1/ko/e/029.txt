// 동작 요약: 카메라가 걷는 사람과 같은 속도로 옆으로 이동합니다. 사람은 중앙에 머물고 가까운 기둥은 더 빠르게 지나갑니다.
// 동작 사양:
//   - 카메라: 일정한 1.7 m/s로 오른쪽 이동(4.7 s 동안 x = -4.0 m → +4.0 m). 높이 1.3 m, 정면 방향, 이징 없음.
//   - 피사체: 7.5 m 떨어진 사람이 카메라와 같은 x 위치로 걸으며 중앙에 머뭅니다. 팔과 다리는 sin(u×7)×0.42 rad로 흔들립니다.
//   - 시차: 깊이 4 m에 1.6 m 간격으로 있는 기둥이 가장 빠르게 왼쪽으로 지나가고, 이어 나무·건물(거리 48 m) 순입니다. 산은 거의 움직이지 않습니다.
//   - 오른쪽 위에 "→ 1.7m/s"를 표시합니다.
//   - 반복: 4.7 s마다 시작점으로 즉시 돌아갑니다(기둥과 지면 격자는 연결되지만 배경 건물과 나무는 뛰어 바뀜).
// 활용 상황: 걷거나 달리는 피사체를 따라가며 동작과 이동감을 함께 보여 줄 때 사용합니다.
// 태그: tracking, tracking shot, follow, truck, lateral, sideways, parallax, walk
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera -> https://comnori.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 예제: https://comnori.github.io/motion-prompt/?lang=ko#029
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 05
// 05 トラッキング: 人物と並んで横移動（手前ほど速く流れる）
CELLS[4] = shot((k, w, h, u) => {
  const x = (u - CYC / 2) * 1.7;
  const fgp = []; for (let i = -12; i <= 12; i++) fgp.push([i * 1.6, 4]);
  world(k, w, h, cam({ x, y: 1.3 }), { person: { x, z: 7.5, walk: u * 7 }, fg: fgp });
  return '→ 1.7m/s';
});
