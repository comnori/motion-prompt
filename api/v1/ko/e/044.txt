// 동작 요약: 현재 화면 위에 다음 화면을 겹쳐 불투명도를 높입니다. 중간에는 두 화면이 함께 비칩니다.
// 동작 사양:
//   - 연결: 1.5 s부터 3.0 s까지 1.5 s. 다음 화면의 불투명도는 0 → 100%입니다.
//   - 이징: quadratic ease-in-out(약 cubic-bezier(0.45,0,0.55,1)). 2.25 s에 50%입니다.
//   - 이전 화면은 완전히 불투명한 상태로 아래에 유지하고 다음 화면을 위에 그립니다(이전 화면을 먼저 흐리게 하지 않음).
//   - 카메라: 두 화면 모두 고정(A는 높이 1.4 m, B는 높이 1.6 m와 피치 +0.1 rad). 피사체도 움직이지 않습니다.
//   - 0–1.5 s에는 이전 화면만, 3.0–4.7 s에는 다음 화면만 보입니다.
//   - 4.7 s마다 A→B와 B→A를 번갈아 표시합니다(왕복 9.4 s). 오른쪽 위에는 "A → B" / "B → A"를 표시합니다.
// 활용 상황: 시간이나 장소가 부드럽게 바뀌거나 회상으로 넘어갈 때 사용합니다.
// 태그: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#044
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 20
// 20 クロスディゾルブ
CELLS[19] = shot(abCell((k, w, h, u, A, B) => blend(k, kk => A(kk, w, h), kk => B(kk, w, h), eIOs(P(u, 1.5, 3.0)))));
