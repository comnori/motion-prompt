// 팔로 샷 / Follow shot
// 팩: camera2 (카메라 움직임과 장면 전환 2) · element 06 · 분류: 카메라 움직임
// 동작 요약: 구불구불 걷는 사람을 몇 미터 뒤에서 같은 경로로 따라가며 뒷모습이 화면 중앙 부근에 머뭅니다.
// 동작 사양:
//   - 경로: 사람이 x = 1.8·sin(2.2s), 깊이 z = 4 + 9s(s는 0부터 1) 곡선을 따라 거리 4 m에서 13 m로 걷습니다.
//   - 카메라: 같은 곡선의 s-0.4 위치(약 3.6–3.9 m 뒤)에서 항상 사람을 향합니다. yaw = atan2(person x - camera x, person z - camera z), 높이 1.5 m.
//   - 시간: 0.3 s부터 4.2 s까지(3.9 s), cubic ease-in-out(약 cubic-bezier(0.65,0,0.35,1)). 팔·다리는 sin(s×30)×0.42 rad로 흔들립니다.
//   - 사람의 뒷모습은 중앙 부근에 있고 길 옆 기둥·바위가 전경을 지나갑니다(#029 Tracking shot은 옆에서 나란히 이동).
//   - 복귀: 마지막 0.5 s 동안 시작 화면으로 크로스페이드합니다(한 번 = 4.7 s). 오른쪽 위에 FOLLOW 3.6–3.9m를 표시합니다.
// 활용 상황: 인물과 함께 장소에 들어가거나 게임 같은 3인칭 시점을 만들 때 사용합니다.
// 태그: follow shot, follow, behind, third person, trail, walk, camera move
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#174
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 06
// 06 フォローショット: 蛇行して歩く人物の後ろを、少し遅れて同じ道筋でついていく（#029 トラッキングは真横に並ぶ）
CELLS[5] = shot(camCell((k, w, h, p) => {
  const path = s => [1.8 * Math.sin(s * 2.2), 4 + s * 9];
  const [px, pz] = path(p), [cx, cz] = path(p - 0.4);
  world(k, w, h, cam({ x: cx, z: cz, y: 1.5, yaw: Math.atan2(px - cx, pz - cz) }), { person: { x: px, z: pz, walk: p * 30 }, fg: [[-2.4, 7], [2.6, 9.5, 'rock'], [-1.5, 12]] });
}, p => `FOLLOW ${Math.hypot(1.8 * Math.sin(p * 2.2) - 1.8 * Math.sin((p - 0.4) * 2.2), 3.6).toFixed(1)}m`, 0.3, 4.2));
