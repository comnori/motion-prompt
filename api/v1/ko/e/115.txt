// 흑백 / Black and white
// 팩: photo (사진 표현·조명·스타일) · element 19 · 분류: 색조와 마무리 표현
// 동작 요약: 같은 풍경에서 색이 빠집니다. 해와 인물의 밝은 면도 회색이 되어 밝기만으로 형태를 구분합니다.
// 동작 사양:
//   - 장면 3: 왼쪽에 흉상(머리 중심 x 140, y 82, 반지름 28 px), 오른쪽에 언덕·집·나무·해(x 432, y 54, 반지름 15 px)가 있습니다.
//   - 변환: 각 색을 휘도(0.2126R + 0.7152G + 0.0722B)의 회색으로 바꾸고 140을 기준으로 대비를 ×1.25 적용합니다.
//   - 예: 인물 #4D5A75 → 약 #4D4D4D, 해 #F5A524 → 약 #B5B5B5.
//   - 시간: 0.4 s부터 1.4 s까지 효과가 나타나고 4.0 s까지 유지한 뒤 4.8 s까지 사라집니다(한 번 = 5 s, cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
// 활용 상황: 시대를 타지 않는 느낌을 주거나 색보다 형태·빛·표정이 중요할 때 사용합니다.
// 태그: black and white, monochrome, b&w, grayscale, desaturated, classic
// 크기: 539x208 px · 반복 주기: 5 s
// 필요한 코드: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#115
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
