// 팩: camera2 (카메라 움직임과 장면 전환 2) · element 11 · 분류: 앵글과 구도
// 동작 요약: 인물의 눈으로 봅니다. 걸음의 흔들림과 아래쪽 손이 1인칭임을 보여 주고 앞의 사람이 나를 향해 손을 흔듭니다.
// 동작 사양:
//   - 카메라: 눈높이 1.6 m에서 0 m → 3.2 m 전진합니다. 0.3–4.2 s(3.9 s), cubic ease-in-out(약 cubic-bezier(0.65,0,0.35,1)).
//   - 걸음 흔들림: 높이 ±3 cm(4.7 s당 6주기), 롤 ±0.008 rad(3주기). 이동 중에만 적용합니다.
//   - 손: 아래 양 모서리에 파란 둥근 손(중앙에서 ±178 px), 오른손에 흰 휴대폰. 몸과 함께 움직여 손은 고정되고 세상이 흔들립니다.
//   - 7.5 m 앞의 상대는 1.6–3.4 s에만 양팔을 들고 나를 향해 흔듭니다. 전경에는 기둥 두 개가 있습니다.
//   - 복귀: 마지막 0.5 s 동안 시작 화면으로 크로스페이드합니다(한 번 = 4.7 s). 오른쪽 위에 POV를 표시합니다.
// 활용 상황: 관객을 인물의 위치에 놓거나 게임·VR 느낌을 줄 때 사용합니다.
// 태그: pov, point of view, first person, subjective, eyes, hands, angle
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera2 -> https://comnori.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 예제: https://comnori.github.io/motion-prompt/?lang=ko#179
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 11
// 11 POVショット: 登場人物の目で見た画。歩く上下動と画面下の両手で一人称だと分かる。前の人物が振り向いて手を振る
CELLS[10] = shot(camCell((k, w, h, p, u) => {
  const z = lerp(0, 3.2, p), T = u * 2 * Math.PI / CYC;
  const bob = Math.sin(T * 6) * 0.03 * (p > 0 && p < 1 ? 1 : 0);
  world(k, w, h, cam({ z, y: 1.6 + bob, roll: Math.sin(T * 3) * 0.008 * (p > 0 && p < 1 ? 1 : 0) }), {
    person: { z: 7.5, armUp: u > 1.6 && u < 3.4, walk: 0 }, fg: [[-1.8, 2.6], [2.2, 3.8]],
    after: (kk) => {   // 両手（画面の下の両端から入る。体と一緒に動くので、揺れるのは世界のほう）
      kk.fillStyle = C.blue;
      [-1, 1].forEach(sx => { kk.save(); kk.translate(sx * 178, 64); kk.rotate(sx * -0.5); kk.fillStyle = C.blue; rr(kk, -34, -28, 68, 120, 30); kk.fill(); if (sx > 0) { kk.fillStyle = '#fff'; rr(kk, -17, -62, 34, 54, 6); kk.fill(); kk.strokeStyle = C.blue; kk.lineWidth = 3; rr(kk, -17, -62, 34, 54, 6); kk.stroke(); } kk.restore(); });
    }
  });
}, p => 'POV', 0.3, 4.2));
