// 동작 사양:
//   - 광각 초점 거리 220 px(표시 16 mm), 높이 4.5 m, 피치 -0.06 rad. 카메라는 -5 m → -2.5 m로 전진합니다.
//   - 타이밍: 0.3–4.2 s(3.9 s), cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1).
//   - 건물 여덟 채가 30 m 구간에 펼쳐집니다. 오른쪽의 높이 16 m 탑은 거리 36 m에 있고, 구름 세 개와 산을 배치합니다. 작은 사람은 왼쪽 1 m, 거리 12 m에 있습니다.
//   - 장소 설명은 0.9–1.3 s에 나타납니다. 158×30 px 흰색 카드와 파란 왼쪽 막대, ‘EXT. CITY – DAY’ 문구가 8 px 올라오며 페이드인한 뒤 유지됩니다.
//   - 4.7 s 반복의 마지막 0.5 s 동안 페이드합니다. 상단에는 ‘16 mm WIDE’를 표시합니다.
// 활용 상황: 장면이 벌어지는 장소를 소개하거나 시간·장소의 변화를 알릴 때 사용합니다.
// 태그: establishing shot, wide shot, location, opening, scene setting, aerial, framing
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera2 -> https://comnori.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 예제: https://comnori.github.io/motion-prompt/?lang=ko#183

// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 15
// 15 エスタブリッシングショット: 広角・高い位置から街全体を見せる引きの画。ゆっくり寄りながら場所の表示が出る
CELLS[14] = shot(camCell((k, w, h, p, u) => {
  const clouds = [[-30, 20, 110, 2.6], [20, 26, 150, 3.2], [60, 17, 95, 2]];
  world(k, w, h, cam({ f: 220, y: 4.5, pitch: -0.06, z: lerp(-5, -2.5, p) }), { city: true, clouds, tower: [16, 36], person: { x: -1, z: 12 } });
  const a = P(u, 0.9, 1.3);   // 場所の表示（左下）
  if (a > 0) { k.save(); k.globalAlpha = a; k.translate(30, h - 52 + (1 - a) * 8); k.fillStyle = 'rgba(255,255,255,.9)'; rr(k, 0, 0, 158, 30, 6); k.fill(); k.fillStyle = C.blue; k.fillRect(0, 0, 4, 30); txt(k, 'EXT. CITY – DAY', 14, 15.5, `600 14px ${MONO}`, C.ink, 'left', 'middle'); k.restore(); }
}, p => `${mm(220)} WIDE`, 0.3, 4.2));
