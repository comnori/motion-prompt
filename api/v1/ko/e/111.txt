// 색수차 / Chromatic aberration
// 팩: photo (사진 표현·조명·스타일) · element 15 · 분류: 렌즈와 카메라 효과
// 동작 요약: 거리 화면을 빨강·초록·파랑으로 분리한 뒤 조금씩 다른 크기로 겹칩니다. 사람·건물·가로등의 경계에 빨강·시안 테두리가 생기고 양옆으로 갈수록 커집니다.
// 동작 사양:
//   - 장면 2: 거리 모퉁이. y 132–162의 도로 뒤에 건물·나무·가로등(x 114, 292, 494)이 있습니다. 왼쪽 앞에 사람이 서 있습니다(발 x 176, y 200, 키 124 px).
//   - 분리: 이미지에 빨강 #FF0000, 초록 #00FF00, 파랑 #0000FF를 각각 곱해 세 복사본을 만들고 검은 바탕 위에 더합니다.
//   - 중심 기준 배율: 빨강 1 + 2s, 초록 1 + s, 파랑 1. s = 0 → 0.02.
//   - 오프셋: 양옆 가장자리에서 빨강과 파랑은 약 11 px 떨어지고 중심에서는 0입니다.
//   - 시간: 0.4 s부터 1.4 s까지 효과가 나타나고 4.0 s까지 유지한 뒤 4.8 s까지 사라집니다(한 번 = 5 s, cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
// 활용 상황: 오래된 렌즈·VHS·글리치의 불완전한 느낌을 더할 때 사용합니다.
// 태그: chromatic aberration, color fringing, rgb split, lens aberration, fringe, glitch
// 크기: 539x208 px · 반복 주기: 5 s
// 필요한 코드: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#111
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 15
// 色収差: 赤・緑・青を少しずつ違う大きさで重ね、画面の端ほど縁に赤と青のずれが出る
CELLS[14] = cell((k, u) => {
  const a = env(u), s = 0.02 * a, cx = CW / 2, cy = CH / 2;
  if (s < 0.0005) { stageStreet(k, BASE); return; }
  const [S, ks] = layer('ca'); stageStreet(ks, BASE);
  k.fillStyle = '#000000'; k.fillRect(0, 0, CW, CH);
  for (const [col, sc] of [['#FF0000', 1 + 2 * s], ['#00FF00', 1 + s], ['#0000FF', 1]]) {
    const [L, kl] = layer('ca-' + col); kl.drawImage(S, 0, 0); kl.globalCompositeOperation = 'multiply'; kl.fillStyle = col; kl.fillRect(0, 0, CW, CH); kl.globalCompositeOperation = 'source-over';
    k.save(); k.globalCompositeOperation = 'lighter'; k.translate(cx, cy); k.scale(sc, sc); k.translate(-cx, -cy); k.drawImage(L, 0, 0); k.restore();
  }
});
