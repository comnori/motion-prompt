// 동작 요약: 화면 대부분이 어둠에 잠기고 해가 사라집니다. 옆에서 빛을 받은 흉상 오른쪽 테두리만 밝게 남고 히스토그램 봉우리는 왼쪽으로 이동합니다.
// 동작 사양:
//   - 장면 3: 왼쪽에 흉상(머리 중심 x 140, y 82, 반지름 28 px), 오른쪽에 언덕·집·나무·해(x 432, y 54, 반지름 15 px)가 있습니다.
//   - 색: 하늘 #FAF9F7 → #2B2D33, 언덕 → #313339·#36383E, 지면 → #24252A, 인물 → #25272E. 해와 고리는 하늘색이 되어 사라집니다.
//   - 흉상의 밝은 오른쪽 가장자리는 유지하며 #FFC75A → #FFB547로 바뀝니다.
//   - 히스토그램: 봉우리 중심 0.56 → 0.14, 너비 0.2 → 0.08.
//   - 시간: 0.4 s부터 1.4 s까지 효과가 나타나고 4.0 s까지 유지한 뒤 4.8 s까지 사라집니다(한 번 = 5 s, cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
// 활용 상황: 고급스럽거나 긴장감·신비감 있는 이미지에 사용합니다.
// 태그: low-key, low key, dark, black background, moody, dramatic, chiaroscuro
// 크기: 539x208 px · 반복 주기: 5 s
// 필요한 코드: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#114
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 18
// ローキー: 画面の大半が暗く沈み、横からの光が当たる縁だけが浮かぶ
CELLS[17] = cell((k, u) => {
  const a = env(u);
  const LOW = Object.assign({}, DARK, { sun: DARK.sky, glow: DARK.sky, person: '#25272E', lit: '#FFB547' });
  stageLand(k, pal(BASE, LOW, a));
  histo(k, lerp(0.56, 0.14, a), lerp(0.2, 0.08, a));
});
