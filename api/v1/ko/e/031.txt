// 팩: camera (카메라 움직임과 장면 전환) · element 07 · 분류: 카메라 움직임
// 동작 요약: 카메라가 올라가면서 아래로 기울어 사람을 내려다봅니다.
// 동작 사양:
//   - 카메라: 높이 1.4 m에서 9 m로 올라가며 동시에 0 m → 1.5 m 전진합니다.
//   - 방향: 8 m 앞의 사람이 프레임 안에 있도록 아래로 기울입니다. pitch = -0.86 × atan2(height - 1.0, 8 - forward), 약 -2.5° → -44°.
//   - 시간: 0.5 s부터 3.4 s까지(2.9 s), cubic ease-in-out(약 cubic-bezier(0.65,0,0.35,1)).
//   - 피사체: 사람은 움직이지 않습니다. 카메라가 올라가면서 사람이 작아지고 지면 격자가 화면을 채우며 수평선은 위로 사라집니다.
//   - 복귀: 3.4–4.2 s에 정지한 뒤 마지막 0.5 s 동안 시작 화면으로 크로스페이드합니다(한 번 = 4.7 s).
//   - 오른쪽 위에 높이를 표시합니다(↑ 1.4m → ↑ 9.0m).
// 활용 상황: 장면 끝에서 사람에게서 멀어지거나 장소의 규모를 드러낼 때 사용합니다.
// 태그: crane, crane up, jib, boom up, rise, high angle, camera move
// 크기: 539x208 px · 반복 주기: 9.4 s
// 필요한 코드: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 예제: https://showheyohtaki.github.io/motion-prompt/?lang=ko#031
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (호출하는 쪽에서 화면 지우기와 save/restore 처리), w·h = 크기, u = 초 (0 이상, 반복 주기 미만). u만으로 화면이 결정됩니다.
// 아래부터 항목 코드입니다. CELLS, 상수와 보조 함수는 kit에 있습니다.

// @element 07
// 07 クレーンアップ: カメラが上昇し、見下ろしになる
CELLS[6] = shot(camCell((k, w, h, p) => {
  const y = lerp(1.4, 9, p), z = lerp(0, 1.5, p);
  world(k, w, h, cam({ y, z, pitch: -0.86 * Math.atan2(y - 1.0, 8 - z) }), { person: { z: 8 } });
}, p => `↑ ${lerp(1.4, 9, p).toFixed(1)}m`));
