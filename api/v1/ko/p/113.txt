Motion Prompt #113

뜻: 밝고 흰색 위주이며 그림자가 아주 옅은 사진
예제에서 보이는 동작: 풍경과 사람이 흰색에 가까운 밝은 색과 아주 옅은 그림자로 바뀌며 오른쪽 아래 히스토그램 봉우리가 오른쪽으로 이동합니다.
동작 사양:
- 장면 3: 왼쪽에 흉상(머리 중심 x 140, y 82, 반지름 28 px), 오른쪽에 언덕·집·나무·해(x 432, y 54, 반지름 15 px)가 있습니다.
- 색: 하늘 #FAF9F7 → #FFFFFF, 언덕 #EAEDF1 → #F5F6F8, 인물 #4D5A75 → #B9C0CE, 그림자 #33405A → #A6AEBF, 해 #F5A524 → #FFD889.
- 히스토그램(96×46 px, 막대 20개): 봉우리 중심 0.56 → 0.85, 너비 0.2 → 0.09.
- 시간: 0.4 s부터 1.4 s까지 효과가 나타나고 4.0 s까지 유지한 뒤 4.8 s까지 사라집니다(한 번 = 5 s, cubic ease-in-out, 약 cubic-bezier(0.65,0,0.35,1)).
활용 상황: 깨끗하고 가볍고 부드러운 제품·인물 사진에 사용합니다.
