“스크롤 배경색 전환 (Background color change on scroll)”를 사용해 주세요. “랜딩 페이지와 웹 효과 2”에 있는 용어입니다.
Motion Prompt #148

뜻: 섹션에 따라 페이지 배경색이 바뀜
예제에서 보이는 동작: 새 섹션에 들어갈 때 페이지 전체 배경이 크림·네이비·연파랑으로 섞여 바뀌고 어두운 배경에서는 글자가 흰색이 됩니다.
동작 사양:
- 511 × 168 뷰포트. 섹션 세 개는 각각 168 px(한 화면)입니다. 스크롤: 0.3–1.2 s에 0→168 px, 1.8–2.7 s에 168→336, 3.3–4.4 s에 336→0(cubic ease-in-out). 한 번은 4.7 s(팩의 9.4 s 주기마다 두 번)입니다.
- 배경색: 아침 #FFEBD9 → 밤 #1E2A4A → 휴일 #DDE6FF. 페이지 전체 뒤에 한 색으로 칠하고 섹션 경계를 지날 때 섞습니다.
- 혼합: 다음 섹션까지 스크롤의 5%–95%에서 0→1(quadratic ease-in-out). 시간이 아닌 스크롤 위치로 결정합니다.
- 밤으로 바뀔 때 제목은 네이비→흰색, 본문 막대는 베이지→청회색입니다. 섹션 라벨(01 MORNING …)은 주황색을 유지합니다.
- 각 섹션 그림(해·달과 별·산 사진)은 페이지와 함께 움직이고 스크롤바 손잡이도 따라갑니다.
활용 상황: 장마다 분위기가 다른 이야기형 페이지나 낮·밤·계절을 대비할 때 사용합니다.
