Motion Prompt #064

뜻: 번호 버튼으로 페이지를 이동함
예제에서 보이는 동작: 페이지 번호 2와 3을 누르면 파란 원이 옮겨가고 위 목록이 바뀝니다. 마지막에는 1로 돌아갑니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. “‹ 1 2 3 4 5 ›”를 y 160에 가운데 정렬합니다. 각 지름 36, 간격 8 px. 현재 페이지는 반지름 18의 파란 원과 흰 글자로 표시합니다.
- 커서는 1.0 s에 2, 2.1 s에 3, 3.3 s에 1을 클릭합니다.
- 파란 원은 0.2 s 동안 easeInOutCubic으로 페이지당 44 px 이동합니다(3에서 1로는 한 번에 88 px).
- 위의 세 줄 목록은 1.05, 2.15, 3.35 s 전후 각각 0.2 s 안에 불투명도 1 → 0 → 1로 변하며 최저점에서 내용이 교체됩니다.
활용 상황: 검색 결과·기사 등 긴 목록을 번호가 있는 페이지로 나눌 때 사용합니다.
