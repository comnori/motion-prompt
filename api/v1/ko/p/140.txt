“페이지 말림 (Page curl)”를 사용해 주세요. “모션 그래픽 움직임 2”에 있는 용어입니다.
Motion Prompt #140

뜻: 종이 모서리가 말려 넘어가며 다음 페이지를 드러냄
예제에서 보이는 동작: 페이지 모서리가 들려 접혀 넘어가면서 아래의 다음 페이지가 드러납니다.
동작 사양:
- 페이지 1(흰색) → 페이지 2(크림색) → 페이지 1을 각각 2.35 s씩 표시합니다. 오른쪽 아래 모서리에서 0.35–1.75 s(1.4 s) 동안 말립니다(quadratic ease-in-out).
- 접힘 선은 모서리에서 정규화한 방향 (−1, −0.42)으로 0→600 px 이동합니다.
- 접힘 선 너머 영역을 선 기준으로 반전해 종이 뒷면(옅은 회색 또는 베이지)을 만듭니다. 그림자(블러 14, 오프셋 4, 4)와 흰 2 px 가장자리를 적용합니다.
- 종이가 들린 자리에 다음 페이지가 보이고 접힘을 따라 50 px의 그림자 그라데이션을 둡니다.
활용 상황: 책·카탈로그·앨범·챕터 전환처럼 종이 질감이나 이어 읽는 느낌이 어울릴 때 사용합니다.
