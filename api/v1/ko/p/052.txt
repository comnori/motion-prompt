Motion Prompt #052

뜻: 제목을 누르면 내용이 펼쳐지거나 접힘
예제에서 보이는 동작: 세 제목 중 첫 번째를 누르면 내용이 펼쳐지고 아래 행이 밀려납니다. 다시 누르면 접힙니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. 제목 세 개(너비 494, 높이 34, 모서리 반지름 8, 간격 6)의 오른쪽에 아래 화살표를 둡니다.
- 커서는 0.95 s에 첫 제목에 도착하고 1.0 s와 3.3 s에 클릭합니다.
- 열림 정도 ex: 1.0–1.35 s에 easeInOutCubic으로 0→1, 3.3–3.62 s에 1→0.
- 첫 행의 높이는 34에서 92로 증가(+58·ex)하여 아래 행을 밀어냅니다. 내용 두 줄은 행 영역으로 클리핑하고 불투명도 ex로 나타냅니다.
- 열리는 동안 화살표를 180°·ex 회전하고 테두리를 옅은 파랑, 제목을 파랑으로 바꿉니다.
활용 상황: FAQ나 긴 설명에서 제목을 훑어보고 필요한 내용만 펼치게 할 때 사용합니다.
