“페이지 전환 (Page transition)”를 사용해 주세요. “랜딩 페이지와 웹 효과”에 있는 용어입니다.
Motion Prompt #092

뜻: 애니메이션으로 두 페이지를 이어 줌
예제에서 보이는 동작: 작업 목록의 카드를 누르면 주황 패널이 왼쪽에서 화면을 덮습니다. URL이 바뀌고 패널이 오른쪽으로 나가 상세 페이지가 보입니다. 목록으로 돌아갈 때도 같은 전환을 사용합니다.
동작 사양:
- 0.8 s에 카드를 클릭합니다. 0.9–1.3 s에 주황색 전체 뷰포트 패널(중앙 로고)이 왼쪽에서 들어와 모두 덮습니다(cubic ease-in-out).
- 완전히 덮인 1.3 s에 페이지와 주소창 URL(/works → /works/02)을 바꿉니다.
- 1.4–1.85 s에 패널이 오른쪽으로 나갑니다(cubic ease-in-out).
- 3.0 s에 “← 목록으로”를 클릭합니다. 패널은 3.1–3.5 s에 들어오고 3.5 s에 페이지가 바뀌며 3.6–4.05 s에 나갑니다.
- 패널은 헤더를 포함한 뷰포트 전체를 덮습니다.
활용 상황: 브랜드 사이트나 포트폴리오에서 페이지 사이를 연결할 때 사용합니다.
