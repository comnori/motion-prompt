“더치 앵글 (Dutch angle)”를 사용해 주세요. “카메라 움직임과 장면 전환”에 있는 용어입니다.
Motion Prompt #036

뜻: 화면을 대각선으로 기울임
예제에서 보이는 동작: 수평이던 카메라가 렌즈 축을 중심으로 회전한 뒤 수평선이 기울어진 상태를 유지합니다.
동작 사양:
- 카메라: 위치 고정(높이 1.5 m), 롤 회전만 0 → 0.36 rad(약 21°) 적용. 화면 전체가 프레임 중심을 기준으로 회전합니다.
- 시간: 0.6 s부터 2.2 s까지(1.6 s), cubic ease-in-out(약 cubic-bezier(0.65,0,0.35,1)).
- 피사체: 사람이 7 m 앞에 서 있습니다. 수평선·건물·사람이 모두 같은 각도로 기울어집니다.
- 정지: 2.2 s부터 4.2 s까지 기울어진 상태를 유지하여 구도를 볼 시간을 줍니다.
- 복귀: 마지막 0.5 s 동안 수평인 시작 화면으로 크로스페이드합니다(한 번 = 4.7 s).
- 오른쪽 위에 각도를 표시합니다(∠ 0° → ∠ 21°).
활용 상황: 불안·긴장이나 무언가 잘못되었다는 느낌을 표현할 때 사용합니다.
