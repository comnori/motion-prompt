“좋아요 버튼 애니메이션 (Like button animation)”를 사용해 주세요. “랜딩 페이지와 웹 효과 2”에 있는 용어입니다.
Motion Prompt #166

뜻: 좋아요를 누르면 하트가 튀고 주변으로 조각이 퍼짐
예제에서 보이는 동작: 하트를 누르면 빨갛게 채워져 튀듯 커지고 주변에 입자가 터지며 숫자가 하나 늘어납니다. 다시 누르면 취소됩니다.
동작 사양:
- 511 × 168 뷰포트의 게시물 카드에 윤곽선 하트(두께 2.4)와 오른쪽 숫자 128을 둡니다. 0.9 s에 클릭하고 3.3 s에 다시 눌러 취소합니다. 한 번 4.7 s(9.4 s마다 두 번).
- 클릭 전 0.1 s에 0.78×로 눌립니다. 클릭 순간 빨강 #F23D5C로 채우고 0.12 s 동안 0.78 → 1.45×로 커진 뒤(cubic ease-out) 1 + 0.45·e^(−7t)·cos(15t)로 1×에 안정됩니다.
- 클릭 후 0.08–0.58 s: 빨간 고리(반지름 15 → 33, 불투명도 0.5 → 0)와 작은 입자 여섯 개(빨강·노랑·주황)가 여섯 방향으로 반지름 24→37까지 퍼지며 사라집니다.
- 숫자: 클릭 후 0.05–0.35 s에 cubic ease-out으로 128이 위로 나가고 빨간 129가 아래에서 들어옵니다. 취소하면 아래로 돌아가 128이 됩니다.
- 취소: 하트는 윤곽선으로 돌아가고 클릭 전후 0.4 s에 0.84×로 줄었다 복귀합니다(입자 없음).
활용 상황: 좋아요·즐겨찾기·저장 입력을 명확하고 기분 좋게 확인해 줄 때 사용합니다.
