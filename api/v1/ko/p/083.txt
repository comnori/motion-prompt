“커서 팔로워 (Cursor follower)”를 사용해 주세요. “랜딩 페이지와 웹 효과”에 있는 용어입니다.
Motion Prompt #083

뜻: 도형이 약간 늦게 마우스 포인터를 따라감
예제에서 보이는 동작: 커서가 페이지를 움직이면 주황색 원이 조금 뒤처져 따라옵니다.
동작 사양:
- 커서 경로: x = 255 + 175·sin(2πt/4.8), y = 86 + 46·sin(4πt/4.8). 옆으로 누운 팔자 경로를 4.8 s마다 한 바퀴 돕니다.
- 원: 반지름 17, 주황색, 불투명도 0.88. 커서 아래에 그립니다.
- 추적 규칙: 매 프레임(60 fps) 남은 거리의 12%를 이동합니다(x += (cursor x − x) × 0.12).
- 화살표 커서는 계속 표시합니다.
활용 상황: 브랜드 사이트나 포트폴리오에 직접 반응하는 듯한 재미를 더할 때 사용합니다.
