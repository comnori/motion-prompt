“빈 상태 (Empty state)”를 사용해 주세요. “UI 컴포넌트 이름”에 있는 용어입니다.
Motion Prompt #072

뜻: 목록에 표시할 내용이 없을 때 보여 주는 화면
예제에서 보이는 동작: 두 목록 행을 휴지통 아이콘으로 삭제하면 빈 상자 그림과 “아직 없습니다” 안내, “추가” 버튼이 나타납니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. 두 줄 목록의 행은 494×48, 모서리 반지름 8이며 오른쪽에 휴지통 아이콘이 있습니다.
- 커서는 0.95 s와 1.65 s에 휴지통을 클릭합니다. 각 행은 0.3 s 동안 easeInOutCubic으로 60 px 왼쪽으로 움직이며 사라지고, 둘째 행은 58 px 위로 올라 첫 자리를 채웁니다.
- 1.95–2.3 s에 빈 상태가 8 px 올라오며 선형으로 나타납니다: 파란 선으로 그린 수신함, “아직 없습니다”(16 px, 일본어), 파란 “추가” 버튼(112×34).
- 커서가 3.3 s에 “추가”를 클릭합니다. 빈 상태는 3.25–3.45 s에 사라지고 두 행은 3.35–3.7 s에 easeOutCubic으로 왼쪽에서 돌아옵니다.
활용 상황: 처음 사용하는 화면이나 검색 결과가 없는 화면에서 다음 행동을 안내할 때 사용합니다.
