“휩 팬 (Whip pan)”를 사용해 주세요. “카메라 움직임과 장면 전환”에 있는 용어입니다.
Motion Prompt #043

뜻: 빠른 팬으로 생기는 흐림을 이용해 다음 샷으로 넘어감
예제에서 보이는 동작: 카메라가 옆으로 아주 빠르게 돌고, 흐릿한 잔상이 생긴 사이에 다음 장면으로 바뀝니다.
동작 사양:
- 연결: 1.7 s부터 2.5 s까지 0.8 s. 처음 0.4 s에는 이전 쇼트가 돌아 나가고 마지막 0.4 s에는 다음 쇼트가 돌아 들어와 멈춥니다.
- 앞 절반: 이전 쇼트의 요 0 → +0.45 rad(약 26°), quadratic ease-in-out. 뒤 절반: 다음 쇼트의 요 -0.45 rad → 0, 같은 이징.
- 교체: 50% 지점에서 바로 바꿉니다. 블러가 가장 강한 순간이므로 전환이 가려집니다.
- 블러: ±1.6프레임(30 fps) 범위의 렌더링 9개를 평균합니다.
- 카메라: 높이 1.4 m이며 회전 구간 외에는 고정합니다. 피사체(A의 사람, B의 자동차와 도시)는 움직이지 않습니다.
- 4.7 s마다 A→B와 B→A를 번갈아 표시합니다(왕복 9.4 s). 오른쪽 위에는 "A → B" / "B → A"를 표시합니다.
활용 상황: 활기를 유지하면서 장소나 주제를 바꿀 때 사용합니다.
