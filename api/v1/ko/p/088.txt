“이탈 의도 팝업 (Exit-intent popup)”를 사용해 주세요. “랜딩 페이지와 웹 효과”에 있는 용어입니다.
Motion Prompt #088

뜻: 방문자가 떠나려는 순간 팝업을 보여 줌
예제에서 보이는 동작: 커서가 페이지 위쪽의 탭·닫기 버튼 방향으로 나가면 화면이 어두워지고 “잠깐!” 팝업이 열립니다. ×로 닫습니다.
동작 사양:
- 커서가 0.7–1.25 s에 페이지에서 브라우저 주소창 쪽으로 올라갑니다(cubic ease-in-out).
- 커서가 뷰포트 위쪽 경계(y = 0, 약 1.07 s)를 넘으면 발동합니다. document의 mouseleave에서 clientY ≤ 0을 검사하는 것과 같습니다.
- 발동 후 0.05–0.45 s에 열립니다(cubic ease-out). 네이비 배경 불투명도 0→0.5, 팝업(260 × 132, 모서리 반지름 12)의 불투명도 0→1과 배율 0.9→1.
- 내부: 제목·주황색 할인 문구·쿠폰 버튼·오른쪽 위 ×.
- 2.9 s에 ×를 클릭하면 0.03–0.25 s 뒤 사라집니다(선형).
활용 상황: 구매나 가입 없이 떠나려는 방문자에게 마지막 제안을 할 때 사용합니다.
