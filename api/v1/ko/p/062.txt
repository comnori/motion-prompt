“범위 슬라이더 (Range slider)”를 사용해 주세요. “UI 컴포넌트 이름”에 있는 용어입니다.
Motion Prompt #062

뜻: 하나의 트랙에서 두 손잡이로 최솟값과 최댓값을 선택함
예제에서 보이는 동작: 가격 슬라이더의 왼쪽 손잡이를 오른쪽으로, 오른쪽 손잡이를 왼쪽으로 끌어 범위를 좁힌 뒤 둘 다 되돌립니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. 트랙은 x 54–488, 높이 8, y 120이며 두 손잡이 사이는 파랑입니다. 범위는 ¥0–¥10,000입니다.
- 손잡이: 흰색, 반지름 13, 3 px 파란 테두리. 드래그 중에는 반지름 15와 반지름 24의 옅은 파란 후광을 적용합니다.
- 하한: 1.0–1.6 s에 0.1 → 0.3(¥1,000 → ¥3,000), 3.55–3.9 s에 복귀. 상한: 2.1–2.6 s에 1.0 → 0.8(¥10,000 → ¥8,000), 2.95–3.3 s에 복귀. 모두 easeInOutCubic입니다.
- 각 손잡이 위에 높이 28의 값 말풍선을 둡니다. 드래그 중 파란 바탕과 흰 글자로 표시합니다. 오른쪽 위의 파란 범위 “¥1,000 – ¥10,000”은 ¥100 단위로 갱신합니다.
- 커서는 드래그하는 손잡이 위에 놓입니다(1.0, 2.1, 2.95, 3.55 s에 누름).
활용 상황: 가격·날짜·크기 등 최솟값과 최댓값이 있는 범위로 필터링할 때 사용합니다.
