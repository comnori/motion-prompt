Motion Prompt #154

뜻: 커서 주변만 조명을 비춘 듯 밝아짐
예제에서 보이는 동작: 어두운 카드 위에서 커서를 움직이면 주변 원형 영역만 밝아지고 가까운 카드 테두리가 빛납니다.
동작 사양:
- 511 × 168 뷰포트. 어두운 페이지 #121828에 어두운 카드 세 개(147 × 116, 모서리 반지름 10)를 둡니다. 한 번은 4.7 s(팩의 9.4 s 주기마다 두 번)입니다.
- 커서는 팔자 경로를 계속 움직입니다: x = 255 + 190·sin(2πt/4.7), y = 92 + 40·sin(4πt/4.7).
- 각 카드 안에만 커서 중심의 흰 방사형 빛을 그립니다. 반지름 115 px, 중앙 불투명도 0.34 → 0이며 밖으로 번지지 않습니다.
- 카드 테두리(두께 2)는 커서와의 거리에 따라 빛납니다. 주황 rgb(255,122,82)의 방사형 빛 반지름은 120 px입니다. 먼 가장자리는 기본선(흰색 8%)만 유지합니다.
- 지연 없이 빛이 커서에 정확히 놓입니다(일반 구현은 좌표를 CSS 변수로 넣어 radial-gradient 중심에 사용).
