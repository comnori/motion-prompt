“브레드크럼 (Breadcrumbs)”를 사용해 주세요. “UI 컴포넌트 이름”에 있는 용어입니다.
Motion Prompt #066

뜻: 사이트 안에서 현재 페이지의 위치를 링크 경로로 표시함
예제에서 보이는 동작: 경로 표시의 “강좌”를 누르면 상위 목록으로 이동하고, 목록 카드를 누르면 상세 페이지로 돌아옵니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. 상단에 “홈 › 강좌 › 웹 디자인”(일본어, 17 px)을 표시합니다. 링크는 파랑, 현재 페이지는 검은 굵은 글자이며 y 46에 구분선을 둡니다.
- 커서는 “강좌” 위에 머물고(0.9–1.2 s에 밑줄) 1.0 s에 클릭합니다.
- 상위 이동 정도: 1.0–1.25 s에 easeInOutCubic으로 0→1. “› 웹 디자인”이 사라지고 “강좌”가 현재 페이지(검은 굵은 글자)가 됩니다.
- 내용은 제목·본문의 상세 페이지에서 풍경 이미지가 있는 카드 세 개(158×118)의 목록으로 크로스페이드합니다.
- 복귀: 커서가 첫 카드로 이동하고(2.45–2.8 s에 파란 윤곽선) 2.7 s에 클릭합니다. 2.7–2.95 s에 상세 페이지로 돌아옵니다.
활용 상황: 계층이 깊은 사이트에서 현재 위치와 상위 페이지로 돌아갈 경로를 보여 줄 때 사용합니다.
