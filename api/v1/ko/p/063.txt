“스테퍼(+/−) (Stepper (+/−))”를 사용해 주세요. “UI 컴포넌트 이름”에 있는 용어입니다.
Motion Prompt #063

뜻: 더하기와 빼기 버튼으로 숫자를 하나씩 조절함
예제에서 보이는 동작: +를 세 번 누르면 1에서 4로, −를 세 번 누르면 다시 1로 바뀝니다. 누를 때마다 숫자가 튀듯 커집니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. (171, 52)에 200×60 상자(모서리 반지름 12)를 놓습니다. 왼쪽 60 px에 −, 오른쪽 60 px에 파란 +, 가운데에 굵은 30 px 숫자.
- 클릭: 0.9, 1.35, 1.8 s에 +(1 → 4), 2.8, 3.25, 3.7 s에 −(4 → 1).
- 클릭 0.05 s 전부터 0.15 s 후까지 누른 구간을 옅은 파랑으로 표시합니다.
- 숫자: 누를 때마다 0.25 s 동안 배율 1.18에서 1로 선형 복귀하며 그동안 파란색입니다.
활용 상황: 수량·인원처럼 작은 정수를 한 번에 하나씩 조절할 때 사용합니다.
