“부드러운 스크롤 (Smooth scroll)”를 사용해 주세요. “랜딩 페이지와 웹 효과”에 있는 용어입니다.
Motion Prompt #093

뜻: 페이지 안의 링크를 누르면 목표 위치까지 부드럽게 이동함
예제에서 보이는 동작: 메뉴의 “요금”을 누르면 요금 섹션으로 부드럽게 내려가고 오른쪽 아래 위 화살표를 누르면 맨 위로 돌아갑니다.
동작 사양:
- 0.9 s에 “요금” 메뉴를 클릭합니다. 0.95–2.0 s 동안 스크롤 0→296 px(1.05 s, cubic ease-in-out).
- 정지 위치 = 요금 섹션 상단(330 px) − 고정 헤더 높이(34 px).
- 스크롤이 60 px를 넘으면 이후 40 px 동안 오른쪽 아래의 맨 위로 버튼(반지름 15)이 나타납니다.
- 3.1 s에 버튼을 클릭합니다. 3.15–4.2 s에 스크롤 296→0(cubic ease-in-out).
- 요금 섹션이 보이는 동안 메뉴의 “요금”을 주황색으로 표시합니다.
활용 상황: 같은 페이지의 메뉴나 목차를 통해 이동할 때 독자가 이동 위치를 파악하게 할 때 사용합니다.
