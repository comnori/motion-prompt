Motion Prompt #055

뜻: 버튼을 누르면 그 버튼을 가리키는 작은 패널이 열림
예제에서 보이는 동작: “상세”를 누르면 버튼을 가리키는 작은 흰 패널이 오른쪽에 열리고, 안의 OK를 누르면 닫힙니다.
동작 사양:
- 542×191 카드에서 4.5 s 주기. (24, 112)의 파란 윤곽선 “상세” 버튼(108×36)을 1.0 s에 클릭합니다.
- 표시 정도 a: 1.0–1.28 s에 easeOutCubic으로 0→1. 불투명도 a, 오른쪽에서 6 px 이동해 들어옵니다.
- 패널: 흰색 300×120, 모서리 반지름 10, 위치 (156, 62), 테두리 1 px, 그림자 블러 22, y 오프셋 6. 왼쪽 경계(y 122–138)의 너비 10 삼각형이 버튼을 가리킵니다.
- 내부: 굵은 제목 막대, 글 두 줄, 윤곽선 버튼 70×26, 파란 OK 버튼 72×26.
- 닫기: 커서가 3.0 s까지 OK (402, 157)로 이동하고 3.3 s에 클릭합니다. a에 (1 − 3.3–3.5 s의 easeInOutCubic)을 곱합니다.
활용 상황: 짧은 설정이나 확인을 관련 버튼 바로 옆에서 처리하게 할 때 사용합니다.
