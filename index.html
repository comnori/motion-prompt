원본 스킬 설치

원본 프로젝트의 스킬을 설치합니다. 설치한 뒤 AI에게 “motion-prompt 모음집을 열어 줘”라고 요청하면 원본 갤러리가 열립니다. 이 개인 페이지에서는 선택 항목이나 프롬프트를 복사해 사용할 수 있습니다.

npx skills add showheyohtaki/motion-prompt

프롬프트로 원본 스킬 설치

아래 문장을 Claude Code나 Codex에 붙여 넣으면 원본 프로젝트의 스킬을 설치하고 사용 방법을 안내합니다.

https://github.com/showheyohtaki/motion-prompt 를 읽고 이 환경에 motion-prompt 스킬을 설치해 줘. 설치가 끝나면 사용 방법을 한국어로 세 줄로 알려 줘.

사용 방법

  1. 1

    AI에게 모음집 열기 요청

    원본 motion-prompt 스킬을 설치한 AI에게 “motion-prompt 모음집을 열어 줘”라고 요청하면 원본 갤러리가 열립니다. 이 개인 페이지에서는 아래의 “선택 항목 복사”를 사용하세요.

  2. 2

    보면서 선택

    원하는 예제의 “선택”을 누르세요. 여러 개를 고를 수 있습니다. 선택한 예제는 화면 아래에 모이며, “오프닝 제목에 사용” 같은 짧은 메모도 적을 수 있습니다.

  3. 3

    AI에게 보내고 작업 요청

    “AI에게 보내기”를 누르면 선택한 예제가 AI에게 전달됩니다. 이어서 “이 영상의 도입부를 이렇게 편집해 줘”라고 요청하세요. 이 버튼은 AI가 갤러리를 열었을 때 표시됩니다.

이렇게 요청하세요

이름이나 번호를 외울 필요는 없습니다. 무엇이라고 부르는지 모를 때는 사전을 찾듯 모음집을 열어 보세요.

  • motion-prompt 모음집을 열어 줘
  • 어떤 카메라 움직임이 있어? 목록을 보여 줘.
  • (예제를 보낸 뒤) 이 영상의 도입부를 이렇게 편집해 줘.

스킬이 없거나 번호를 알고 있다면

스킬이 없는 AI에게는 화면 아래 “선택 항목 복사”로 만든 문장을 붙여 넣으세요. 예제와 사양 URL이 포함됩니다. 하나만 사용할 때는 상세 화면의 “프롬프트 복사”도 가능합니다.

번호를 알고 있다면 “motion-prompt의 #012와 #045를 사용해 줘”처럼 바로 요청할 수도 있습니다.
